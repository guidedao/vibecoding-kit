# Сайт под заказ · лендинг и CRM для заказчика

Практика модуля «Сайт под заказ» курса «Вайбкодинг». Полное задание — в
уроке «Практика: лендинг и CRM для заказчика» на платформе GuideDAO.

Заказчик — падел-клуб «Отскок»: две площадки, шесть кортов, тренеры и
группы. Нужен сайт с онлайн-записью на корт и CRM для администраторов,
тренеров и владельца. Бриф, тексты, бренд и данные — в учебном проекте.

Нужны Node.js 22 или новее, Git и бесплатный проект Supabase. Откройте эту
папку (`client-site`) в агенте и попросите выполнить `npm run setup`.
Появится папка `site` — каркас сайта на Astro с материалами заказчика.
Начните новую сессию агента в папке `client-site/site` и выполните там
`npm install` и `npx playwright install chromium`. Задача и критерии — в
`site/README.md`, автопроверка — `npm run check` в папке `site`.

В `data/` рядом лежат те же файлы данных, что и в учебном проекте: брони,
корты и групповые занятия. Их удобно открыть прямо на GitHub.

Начать заново: удалите папку `site` и снова выполните `npm run setup`.
