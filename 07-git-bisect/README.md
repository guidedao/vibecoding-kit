# 07 · Сломать и вернуть

Практика модуля 7 «Терминал и Git» курса «Вайбкодинг». Полное задание с
шагами и сверкой — в уроке «Сломать и вернуть» на платформе GuideDAO. Здесь
коротко: как подготовить учебный проект и как понять, что практика готова.

## О чём практика

Учебная копия трекера привычек с тестами и историей из восьми коммитов. Один
из коммитов сломал счётчик «Выполнено N из M». Нужно найти его через
`git bisect` и отменить через `git revert`, не трогая остальную работу. Ваш
собственный трекер в этой практике не меняется.

## Подготовка

Нужны Node.js 22 или новее и Git 2.23 или новее. Пакеты ставить не нужно,
`npm install` не нужен.

1. Откройте эту папку (`07-git-bisect`) в агенте и попросите выполнить:

   ```bash
   npm run setup
   ```

2. Появится папка `tracker` — отдельный Git-репозиторий с историей из восьми
   коммитов в ветке `main`. Начните новую сессию агента в папке
   `07-git-bisect/tracker` и дальше работайте только в ней.

Если в Git на вашем компьютере не задано имя автора, `npm run setup` подпишет
коммиты в учебной папке именем «Студент» и скажет об этом.

Команды в папке `tracker`:

| Команда | Что делает |
| --- | --- |
| `npm test` | запускает тесты |
| `npm run check` | автопроверка: смотрит историю, код и тесты |
| `npx serve .` | открывает приложение в браузере, остановка — Ctrl+C (при первом запуске npx скачает пакет `serve`) |

## Когда практика готова

`npm run check` выводит шесть строк с отметкой ✔ и итог
«Итог: 6 из 6. Практика пройдена.»

## Начать заново

Переименуйте или удалите папку `tracker` и снова выполните `npm run setup`.
Всё, что вы меняли в `tracker`, останется только в переименованной папке.

## Если что-то не так

- **«Поиск ещё идёт».** Поиск `git bisect` не завершён: выполните
  `git bisect reset` и запустите проверку снова.
- **«История переписана».** Исходные коммиты пропали из `main`, например
  после `git reset --hard`. Проще начать заново.
- **Windows: `git bisect run npm test` не запускается.** Используйте
  `git bisect run node --test`: это те же тесты.
- **После итога появились строки `npm error ...`.** Некоторые версии npm так
  сообщают, что проверка не пройдена. Ошибки в самом наборе здесь нет.
