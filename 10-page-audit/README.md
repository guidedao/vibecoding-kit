# 10 · Аудит трекера

Практика модуля 10 «Страница: HTML и CSS» курса «Вайбкодинг». Полное задание —
в уроке «Аудит трекера» на платформе GuideDAO.

Нужны Node.js 22 или новее и Git. Откройте эту папку (`10-page-audit`)
в агенте и попросите выполнить `npm run setup`. Появится папка `tracker` —
трекер привычек, который работает мышью, но свёрстан небрежно. Начните новую
сессию агента в папке `10-page-audit/tracker`, выполните там `npm install` и
`npx playwright install chromium` (сеть нужна один раз). Критерии приёмки —
в `tracker/README.md`; автопроверка — `npm run check` в папке `tracker`.

Начать заново: удалите папку `tracker` и снова выполните `npm run setup`.
