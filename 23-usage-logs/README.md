# 23 · Расход по журналам

Практика модуля 23 «Стоимость и выбор модели» курса «Вайбкодинг». Полное
задание — в уроке «Расход по журналам» на платформе GuideDAO.

В папке `logs` — журналы месяца работы над трекером привычек и сайтом для
клуба: Claude Code в `logs/claude/projects` (вместе с субагентами) и Codex
в `logs/codex/sessions`. Устроены они так же, как настоящие журналы на
вашем компьютере, только тексты в них короткие.

Нужен Node.js 22 или новее. Задача — скрипт `usage.mjs` в этой папке, без
зависимостей из npm. Запуск:

```bash
node usage.mjs --claude logs/claude/projects --codex logs/codex/sessions
```

Скрипт печатает JSON:

```json
{
  "claude": { "responses": 0, "input": 0, "cacheWrite": 0, "cacheRead": 0, "output": 0 },
  "codex": { "sessions": 0, "input": 0, "cachedInput": 0, "output": 0, "total": 0 }
}
```

У Claude Code `responses` — число ответов модели, `input` — вход мимо
кэша, `cacheWrite` — запись в кэш, `cacheRead` — чтение из кэша, `output` —
выход. У Codex `sessions` — число сессий, `input` — вход вместе
с кэшированной частью, `cachedInput` — кэшированный вход, `output` — выход,
`total` — итог по полю `total_tokens`. Можно печатать и больше, например
разбивку по дням и моделям: автопроверка смотрит только эти поля. Текст
сообщений и пути к файлам скрипт не печатает.

Автопроверка — `npm run check` в этой папке. Она запускает ваш скрипт на
журналах из `logs` и на двух других наборах из `checks/data` и сверяет
числа. Журналы она не меняет.
