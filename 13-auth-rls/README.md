# 13 · Вход и чужие данные

Практика модуля 13 «Аккаунты и доступ» курса «Вайбкодинг». Полное задание —
в уроке «Вход и чужие данные» на платформе GuideDAO.

Нужны Node.js 22 или новее, Git и проект Supabase из практики «Трекер на
Supabase» с таблицей `habits`. Откройте эту папку (`13-auth-rls`) в агенте
и попросите выполнить `npm run setup`. Появится папка `tracker` — трекер на
Supabase, пока без входа и без RLS. Начните новую сессию агента в папке
`13-auth-rls/tracker` и выполните там `npm install`. Ключи впишите сами в
`tracker/.env.local` по образцу `tracker/.env.example`. Задача и критерии —
в `tracker/README.md`; автопроверка — `npm run check` в папке `tracker`.

Начать заново: удалите папку `tracker` и снова выполните `npm run setup`.
