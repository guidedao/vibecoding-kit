# 15 · Трекер в интернете

Практика модуля 15 «Публикация и эксплуатация» курса «Вайбкодинг». Полное
задание — в уроке «Трекер в интернете» на платформе GuideDAO.

Нужны Node.js 22 или новее, Git, аккаунты GitHub и Vercel и ваш проект
Supabase из прошлых практик. Откройте эту папку (`15-deploy`) в агенте и
попросите выполнить `npm run setup`. Появится папка `tracker` — трекер после
практики «Pro за криптоплатёж». Начните новую сессию агента в папке
`15-deploy/tracker`, заполните там `.env.local` по `.env.example`, выполните
`npm install` и `npx playwright install chromium`. Автопроверка опубликованного
трекера — `npm run check -- --url https://<адрес продакшена>` в папке `tracker`.

Начать заново: удалите папку `tracker` и снова выполните `npm run setup`.
