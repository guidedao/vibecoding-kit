# 19 · Оживить заброшенный проект

Практика модуля 19 «Сопровождение и чужой код» курса «Вайбкодинг». Полное
задание — в уроке «Оживить заброшенный проект» на платформе GuideDAO.

Нужны Node.js 22 или новее и Git. В этой папке выполните `npm run setup`:
появится папка `journal` — «Журнал чтения» с историей прежнего автора.
Начните новую сессию агента в папке `19-legacy/journal` и работайте только
в ней.

Автопроверка — `npm run check` в папке `19-legacy` (из `journal`:
`npm run check --prefix ..`). Она не меняет проект: работает во временной
копии. Автопроверка вносит мутации через `summarize` в `src/stats.js` и
`normalizeEntry` в `src/entries.js`; эти имена и файлы сохраните.

Начать заново: удалите папку `journal` и снова выполните `npm run setup`.
