# 11 · Экспорт и импорт

Практика модуля 11 «Браузер, состояние и данные» курса «Вайбкодинг». Полное
задание — в уроке «Экспорт и импорт» на платформе GuideDAO.

Нужны Node.js 22 или новее и Git. Откройте эту папку (`11-export-import`)
в агенте и попросите выполнить `npm run setup`. Появится папка `tracker` —
трекер привычек с базовыми тестами, но без экспорта и импорта. Начните новую
сессию агента в папке `11-export-import/tracker`, выполните там `npm install`
и `npx playwright install chromium` (сеть нужна один раз). Задача и критерии —
в `tracker/README.md`, спека — в `tracker/docs/spec-export.md`; автопроверка —
`npm run check` в папке `tracker`.

Начать заново: удалите папку `tracker` и снова выполните `npm run setup`.
