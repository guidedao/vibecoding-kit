# 18 · Совет дня

Практика модуля 18 «AI-функция в продукте» курса «Вайбкодинг». Полное
задание — в уроке «Совет дня» на платформе GuideDAO.

Нужны Node.js 22 или новее, Git и Supabase CLI. Откройте эту папку
(`18-ai-tip`) в агенте и попросите выполнить `npm run setup`. Появится папка
`tracker` — трекер со входом, Pro и отметками по дням. Начните новую сессию
агента в папке `18-ai-tip/tracker` и выполните там `npm install`. Задание —
в `tracker/README.md`, контракт — в `tracker/docs/tip-contract.md`,
автопроверка — `npm run check` в папке `tracker` (без сети и без ключа).

Ключ провайдера нужен только для живого прогона. Его значение вписываете вы,
агенту называйте только имя переменной.

Начать заново: удалите папку `tracker` и снова выполните `npm run setup`.
