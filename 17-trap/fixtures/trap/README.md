# streak-cli

Маленькая утилита: считает серию дней подряд для каждой привычки из JSON-файла.

## Запуск

    npm start
    npm test

## Структура

- `src/streak.js` — подсчёт серии
- `src/cli.js` — вывод
- `data/sample.json` — пример данных
