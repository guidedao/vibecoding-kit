# Стиль трекера: спокойная бумага

Пример заполненного `design.md` для трекера привычек. По нему собрана страница `index.html`, скриншоты на
ширине 1280 и 375 px лежат в `shots/`. Свой файл собирайте по той же форме: каждое число записано, у каждого
пункта сказано, откуда он взят.

Базу собрали из пяти референсов: три трекера привычек, приложение для заметок и бумажный ежедневник.
Общее у них: светлый фон, одна колонка, крупный текст строки и один цвет для действия.

## Цвета

- Фон — тёплая бумага `#F6F4EF`. Отдельных карточек нет: строки отделены линией.
- Текст и названия привычек — почти чёрный `#1F1F1F`, контраст с фоном 15:1.
- Второстепенный текст, подсказки и рамка флажка — `#5F5E5A`, контраст 5,9:1.
- Линии между строками — `#DDD9CF`.
- Акцент `#2F6B4F` — только кнопка «Добавить» и заливка отмеченного флажка. Белый текст на нём — 6,3:1.
  Откуда: у четырёх референсов из пяти цвет есть только у главного действия.

## Шрифты

- Golos Text из Google Fonts, с кириллицей: всё, кроме чисел. Текст 16 px, межстрочный 1,5; заголовок
  28 px, вес 600, межстрочный 1,15; подписи 13 px.
- JetBrains Mono, вес 500: счётчик «Выполнено 1 из 3» и даты, 14 px, цифры табличные
  (`font-variant-numeric: tabular-nums`), чтобы число не прыгало при отметке.
- Больше размеров нет: на странице 13, 14, 16 и 28 px.

## Сетка

- Одна колонка до 480 px по центру экрана, текст внутри по левому краю.
- Поля: 16 px по бокам на телефоне, 48 px сверху на компьютере и 24 px на телефоне.
- Строка привычки — от 56 px в высоту, флажок слева, название, кнопка удаления справа.
  Область нажатия у флажка и кнопок — не меньше 44 × 44 px.
- Радиус 6 px у поля и кнопки, 4 px у флажка. Отступы только из ряда 4, 8, 12, 16, 24, 48.

## Движение

- Одно на всю страницу: флажок заливается за 160 мс, кривая `ease-out`.
- Новая строка появляется проявлением за 200 мс, без сдвига соседних.
- При `prefers-reduced-motion: reduce` анимаций нет.

## Чего на странице нет

- Градиентов, теней, свечения и размытия.
- Тёмно-синего или фиолетового фона, неоновых цветов.
- Иконок, эмодзи, плашек-таблеток и конфетти при отметке.
- Текста по центру и больше одного акцентного цвета.
- Серого текста светлее `#5F5E5A`.
