# Пример стиля

Заполненный `design.md` для трекера привычек и страница, собранная по нему. Это образец формы, а не стиль,
который нужно повторить: свой файл вы соберёте из своей базы референсов.

- `design.md` — цвета с ролями, два шрифта с кириллицей, размеры в пикселях, сетка, одно движение и список того,
  чего на странице нет.
- `index.html`, `styles.css` — страница по этому файлу. Значения стоят CSS-переменными в начале `styles.css`.
- `shots/` — скриншоты на ширине 1280 и 375 px. По ним вид сверяют с файлом и со списком запретов.

Файлом пользуются практики «Трекер в интернете» (портфолио) и «Чекпоинт 3. Прототип».
