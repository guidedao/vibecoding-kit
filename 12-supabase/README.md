# 12 · Трекер на Supabase

Практика модуля 12 «Сервер, API и база» курса «Вайбкодинг». Полное задание —
в уроке «Трекер на Supabase» на платформе GuideDAO.

Нужны Node.js 22 или новее, Git и бесплатный проект Supabase. Откройте эту
папку (`12-supabase`) в агенте и попросите выполнить `npm run setup`.
Появится папка `tracker` — трекер с экспортом и импортом из прошлой
практики, данные пока в браузере. Начните новую сессию агента в папке
`12-supabase/tracker`, выполните там `npm install` и
`npx playwright install chromium`. Адрес и publishable key проекта впишите
сами в `tracker/.env.local` по образцу `tracker/.env.example`. Задача и
критерии — в `tracker/README.md`; автопроверка — `npm run check` в папке
`tracker`.

Начать заново: удалите папку `tracker` и снова выполните `npm run setup`.
