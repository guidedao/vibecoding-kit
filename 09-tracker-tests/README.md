# 09 · Тесты трекера

Практика модуля 9 «Тесты» курса «Вайбкодинг». Полное задание — в уроке
«Тесты трекера» на платформе GuideDAO.

Нужны Node.js 22 или новее и Git. Откройте эту папку (`09-tracker-tests`)
в агенте и попросите выполнить `npm run setup`. Появится папка `tracker` —
эталонный трекер привычек без тестов. Начните новую сессию агента в папке
`09-tracker-tests/tracker`, выполните там `npm install` и
`npx playwright install chromium` (сеть нужна один раз). Требования к тестам
и команды — в `tracker/README.md`; автопроверка — `npm run check` в папке
`tracker`.

Начать заново: удалите папку `tracker` и снова выполните `npm run setup`.
