# 04 · Агент сломал тест

Практика модуля 4 «Агентный цикл» курса «Вайбкодинг». Полное задание с
шагами и сверкой — в уроке «Агент сломал тест» на платформе GuideDAO. Здесь
коротко: как подготовить учебный проект и как понять, что практика готова.

## О чём практика

Учебная копия трекера привычек: счётчик «Выполнено N из M», автоматические
тесты и история из пяти коммитов. Последние два коммита сделал кодинг-агент.
После них тесты зелёные, но счётчик после удаления привычки считает неверно.
Вам нужно по истории Git понять, что произошло, вернуть честную проверку и
исправить код. Ваш собственный трекер в этой практике не меняется.

## Подготовка

Нужны Node.js 22 или новее и Git 2.30 или новее. Пакеты ставить не нужно,
`npm install` не нужен.

1. Откройте эту папку (`04-broken-test`) в агенте и попросите выполнить:

   ```bash
   npm run setup
   ```

2. Появится папка `tracker` — отдельный Git-репозиторий учебного проекта со
   своей историей. Начните новую сессию агента в папке
   `04-broken-test/tracker` и дальше работайте только в ней.

Команды в папке `tracker`:

| Команда | Что делает |
| --- | --- |
| `npm test` | запускает тесты |
| `npm run check` | автопроверка: временно портит счётчик в копии проекта тремя способами и смотрит, падают ли тесты |
| `npm start` | открывает приложение на http://localhost:3000, остановка — Ctrl+C (при первом запуске npx скачает пакет `serve`) |

## Когда практика готова

- `npm test` проходит: 10 тестов из 10.
- `npm run check` по всем трём поломкам пишет «Тест ловит поломку: да» и
  заканчивается строкой «Итог: тесты поймали 3 из 3 поломок.»
- `tests/counter.test.js` совпадает с версией из коммита «Счётчик
  выполненных», файлы в `checks/` не менялись.
- В браузере после удаления привычки общее число уменьшается.
- Изменения сохранены коммитом, `git status --short` ничего не выводит.

## Начать заново

Удалите папку `tracker` и снова выполните `npm run setup`. Всё, что вы
меняли в `tracker`, пропадёт.

## Если что-то не так

- **«Мутации не запускались».** `npm test` сейчас красный, поэтому проверять
  тесты на поломки бессмысленно. Сначала добейтесь зелёного `npm test`,
  исправляя код, а не ожидания тестов.
- **«Тест ловит поломку: нет».** Тесты не заметили, что счётчик врёт.
  Прочитайте подсказку под этой строкой.
- **После итога появились строки `npm error ...`.** Некоторые версии npm
  так сообщают, что проверка не пройдена. Ошибки в самом наборе здесь нет.
- **`npm run setup` пишет, что нужен Node.js или Git.** Установите нужную
  версию и запустите команду ещё раз.
- **`npm run check` в папке `04-broken-test` говорит «запускается в папке
  tracker».** Перейдите в `tracker` и запустите проверку там.
