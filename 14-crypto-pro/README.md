# 14 · Pro за криптоплатёж

Практика модуля 14 «Внешние сервисы и платежи» курса «Вайбкодинг». Полное
задание — в уроке «Pro за криптоплатёж» на платформе GuideDAO.

Нужны Node.js 22 или новее, Git и Supabase CLI. Откройте эту папку
(`14-crypto-pro`) в агенте и попросите выполнить `npm run setup`. Появится
папка `tracker` — трекер со входом и лимитом в три привычки. Начните новую
сессию агента в папке `14-crypto-pro/tracker` и выполните там `npm install`.
Задание — в `tracker/README.md`, контракт функции проверки —
в `tracker/docs/payment-contract.md`, автопроверка — `npm run check`
в папке `tracker` (сеть не нужна).

Кошелёк — только тестовый. Фразу восстановления и ключи не показывайте агенту.

Начать заново: удалите папку `tracker` и снова выполните `npm run setup`.
